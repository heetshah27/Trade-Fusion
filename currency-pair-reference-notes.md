# Currency-Pair Reference Notes

The supplied public reference presents currency pairs as compact paired circular marks. Its useful interaction principles are immediate recognition, strong contrast between the two currencies, deliberate overlap, and a small-footprint layout suitable for tables and watchlists.

Trade Fusion will not copy the reference artwork. The original implementation will retain text-derived currency glyphs and accessible pair names, while refining the pair treatment into paired market-color tokens with clearer overlap, a small directional separator, and a predictable size scale for ledger, Journal, Analytics, and Backtest views.
