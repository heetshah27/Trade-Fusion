# Scroll-Driven MacBook Backtest Presentation

## Purpose

The desktop landing preview now uses an original Trade Fusion scroll-driven MacBook composition. Its display renders the user-supplied Backtest chart reference as screen content, without using third-party product names, logos, controls, or navigation.

## Asset handling

The chart reference is stored outside the application source tree and served through the managed web asset URL:

`/manus-storage/trade-fusion-backtest-chart-reference_26bb10ef.webp`

## Behavior

| Context | Presentation |
| --- | --- |
| Desktop | The MacBook moves through a small scroll-linked perspective transition and has a Trade Fusion–branded frame, camera, hinge, and base. |
| Reduced motion | The MacBook stays in a stable static position. |
| Portrait mobile | The native compact workspace preview remains in place; the large MacBook is intentionally hidden. |

## Visual review

Desktop review confirmed the chart fits naturally inside the new MacBook frame against the near-black landing surface. Portrait review confirmed the existing phone-first workspace preview remains clear and avoids a scaled-down laptop treatment.
