# Landing Execution Chart and 3D Edge Lighting

## Original chart composition

The landing Backtest preview uses an original dark candlestick execution illustration. It is inspired by general chart-analysis conventions rather than by any third-party product interface or branding.

| Visual cue | Trade Fusion interpretation |
| --- | --- |
| Candlesticks | Teal and rose simulated candles with neutral wicks. |
| Analysis range | A soft blue accumulation-range box with a labeled execution zone. |
| Trade context | Clearly separated long entry, take-profit, stop-loss, and 1:2.4 risk/reward markers. |
| Volume | A low-profile volume band that reinforces chart rhythm without competing with the trade plan. |

## 3D lighting

The near-black hero now uses restrained blue edge-lighting: orbit contours, a perspective grid plane, ambient glow, and floating private/review beacons brighten subtly on fine-pointer interaction. Reduced-motion settings continue to remove the decorative 3D scene; portrait layouts keep the effect quiet so conversion content and the native workspace card remain readable.

## Visual review

Desktop review at 1440×900 confirmed the blue edge light is visible against the near-black canvas without overriding the primary CTA. Portrait review at 390×844 confirmed that the mobile landing remains predominantly near-black with blue limited to intentional action and active-state accents.
