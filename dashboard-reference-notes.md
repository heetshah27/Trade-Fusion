# Dashboard Reference Notes

## Observed dashboard composition

The supplied dashboard image uses a compact dark command-center arrangement: a persistent left navigation rail, a thin utility header, four summary cards, a large performance area, a monthly P&L calendar, and secondary modules for positions, activity, peer performance, and quick statistics. The visual hierarchy relies on dense panels, thin rules, restrained accent color, and a large central data surface.

## Trade Fusion translation

Trade Fusion will not copy the reference visual assets or product branding. The redesign will retain the existing TF navigation and private modules, but will evolve the authenticated Journal landing view into an original command center. The first implementation target is a compact metric strip, private performance review panel, monthly P&L calendar, execution activity, and market-preparation status using the member’s existing private data.

## Trade Fusion command-center structure

The redesigned Journal dashboard uses four compact metric cards for recorded P&L, current-month P&L, win rate, and today’s activity. Its primary row contains a private journal-only performance trend and a current-month P&L calendar. The supporting row contains recent executions, a separate Backtest and macro-preparation desk, and quick statistics. The execution ledger remains below these modules for detail-oriented review and manual trade management.

Every metric is calculated from the authenticated member’s existing live journal records. Backtest data is not used in the recorded P&L, calendar, trend, activity, or quick-stat modules.
