# Trade Fusion Instrument Badge System

Trade Fusion uses original, text-first visual markers rather than copied third-party logos. The badges are deterministic, light-weight, readable at small sizes, and retain accessible market labels.

| Market type | Badge treatment | Examples |
| --- | --- | --- |
| Forex | Two overlapping currency-glyph tokens | EUR/USD, GBP/USD, USD/JPY |
| Metals | Commodity abbreviation | Au for gold, Ag for silver |
| Crypto | Recognizable asset glyph or short code | ₿ for BTC, Ξ for ETH |
| Indices | `IX` market token | NAS100, US30 |
| Equities | Equity token | AAPL, TSLA |
| Options | `OP` contract token | Listed options |

The badge never replaces the symbol text. Trade Fusion preserves the exact recorded instrument label beside the marker so every market remains identifiable without decorative rendering.
