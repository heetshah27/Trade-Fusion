# Instrument Badge Reference Notes

The public [TradingView homepage](https://www.tradingview.com) was reachable but did not expose its interactive symbol list in the sandbox browser. The implementation will therefore use the user-requested **compact, recognizable market marker pattern** as general design inspiration only, without downloading, copying, or presenting TradingView artwork.

Trade Fusion will use an original, accessible badge vocabulary: two-code currency flags for forex pairs, commodity-metal glyph badges, deterministic asset-symbol tokens for crypto, index abbreviations, equity initials, and an options marker. Every badge will retain readable text and an accessible label, so the market is identifiable even when decorative treatment is unavailable.
